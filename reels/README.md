# サロポン 加盟募集リール動画

サロンオーナー向けに「サロポン」のメリットを伝え、加盟につなげるInstagramリール動画。
構成は **テロップ＋ナレーションのみ**（約30秒・縦型1080×1920）。最後のシーンに、内容に合わせて
**加盟店登録URL** か **サロポンサイトURL** のどちらか1つを表示します。

## デザイン・BGM

- テロップのアニメーション：行ごとに下からスライドイン → 強調ワード（`[[ ]]`）は「ドン！」と押し出されてキラキラが飛び、その後ゆっくり脈打つ。
  強調ワードに数字があれば 0 からカウントアップ（例：約76%、100サロン限定）。シーンの終わりは上にスッと抜ける。
  背景のストライプは常にゆっくり流れ、上部の進行バーも伸びていく。最後の登録案内はロゴがポンと弾み、ボタンが脈打ち、URLが下からせり上がる。

- 配色はサロポンカラーの**黄色×黒**で統一。ロゴは `assets/salopon_logo.png`（支給ロゴ）を使用し、
  黄色地を抜いて動画背景になじませています（各シーン左上に小さく、最後のシーンに大きく表示）。
- BGM は `scripts/bgm.py` でその場で作曲・合成する**オリジナル曲**（外部音源なし＝著作権・利用料の心配なし）。
  テンポの良いアップビート（114〜130BPM）で、シーン切り替えに効果音、最後の登録案内の直前に盛り上げ（ライザー＋シンバル）が入ります。
  ナレーション中は自動で音量が下がり、声が聞き取りやすくなっています。音量は Instagram 推奨付近（-14 LUFS）に揃えています。
- 各エピソードの `bgm` で曲調を内容に合わせて指定：
  `style`（`pop` 王道ポップ / `bounce` 弾む・ノリ重視 / `funk` 知的でグルーヴィー）、`bpm`、`key`、
  `prog`（コード進行 `pop` / `lift` / `bounce` / `hope`）、`seed`（メロディの変化）。
  全体の BGM 音量は `config.json` の `bgm_volume`。

## 動画の作り直し・追加

```bash
bash reels/scripts/setup.sh           # 初回のみ（ffmpeg / 日本語フォント / Open JTalk）
python3 reels/scripts/render.py       # 全エピソード生成
python3 reels/scripts/render.py ep03  # 1本だけ生成
```

- 台本は `episodes/epXX_*.json`。`telop` の `[[ ]]` で囲んだ部分が黄色の強調文字になります。
  読み間違いがある場合は `yomi`（ナレーション用の読み）を追加してください。
- URL・最後のシーンの文言・共通ハッシュタグ・話速は `config.json` で変更できます。
- 新しいエピソードは JSON を1つ追加して `render.py` を実行するだけです。
